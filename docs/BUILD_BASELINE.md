# Central Build Baseline

To reduce mismatches between AI agents, use this initial shared baseline unless the team has a documented reason to change it before implementation.

| Tool | Baseline |
|---|---|
| JDK | Java 21 |
| Spring Boot | 3.5.16 |
| Gradle Wrapper | 8.14.3 |
| MySQL | 8.4 LTS recommended |
| JDBC driver | `com.mysql:mysql-connector-j`, version managed by Spring Boot dependency management |
| HTTP/JWT security | Spring Security + OAuth2 Resource Server/Nimbus JWT APIs |
| Backend JSON | Jackson version managed by Spring Boot |
| Swing client JSON | Jackson, using the same Spring Boot BOM in the client module |

Spring Boot 3.5.16's official system requirements list Java 17+ and Gradle 7.6.4+ or 8.4+; Java 21 and Gradle 8.14.3 are within that compatibility range. See [Spring Boot 3.5 system requirements](https://docs.spring.io/spring-boot/3.5/system-requirements.html) and [Gradle 8.14.3 release notes](https://docs.gradle.org/8.14.3/release-notes.html).

## Version ownership

Member 1 owns `settings.gradle.kts`, root/module `build.gradle.kts`, `gradle.properties` and Gradle Wrapper. Other members must not update versions independently. The dependencies listed in the build scripts are the central dependency set; add new dependencies only through a reviewed PR. The client uses the Boot BOM to align Jackson, while Swing and `java.net.http.HttpClient` come from the JDK.

## Bootstrap the wrapper once

From the repository root, with Gradle 8.14.3 available locally, run:

```bash
gradle wrapper --gradle-version=8.14.3
```

Commit `gradlew`, `gradlew.bat`, and `gradle/wrapper/` generated by that command. After this, everyone uses `./gradlew` (macOS/Linux) or `gradlew.bat` (Windows), not a locally installed Gradle. Do not fabricate the wrapper JAR or scripts by hand.

## Approved dependencies

Backend:
- Spring Boot Web MVC (REST API)
- Spring Boot Validation
- Spring Boot JDBC
- Flyway migrations (`flyway-core` + `flyway-mysql`)
- Spring Boot Security
- Spring Boot OAuth2 Resource Server (JWT verification) and Spring Security's `JwtEncoder`/Nimbus support for token issuance
- MySQL Connector/J, version managed by Spring Boot BOM
- Spring Boot Test and Spring Security Test

Swing client:
- Java standard Swing + `java.net.http.HttpClient`
- Jackson Databind, version managed through Spring Boot 3.5.16 BOM
- JUnit Jupiter for tests

Do not add Spring Data JPA, Hibernate ORM, React, Node.js, or another token library without team approval.
